# Marionette

Pose, stage and film your characters in FFXIV's GPose, puppeteer style. Made by Marius Emyr (MusicManBowls), for friends.

This repository only holds releases. To install:

1. In game, type `/xlsettings`, open **Experimental**, and under **Custom Plugin Repositories** paste:
   `https://raw.githubusercontent.com/musicmanbowls/Marionette-Releases/main/repo.json`
2. Tick **Enabled**, press the **+**, then **Save**.
3. Open `/xlplugins`, search for **Marionette** and install it.

Turn Brio off while using Marionette: both change the same skeletons.

Marionette is a modified version of [Brio](https://github.com/Etheirys/Brio), licensed under the GNU General Public License 3.0. Each release has its matching source code beside the plugin.
